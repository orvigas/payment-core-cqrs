## 2026-07-22 — Target stack moved from Spring Boot 3.5.16 to 4.1.0

Governance docs (TECH_STACK.md, CLAUDE.md, backend-engineer rule) now target Spring Boot 4.1.0, the latest stable line. Coordinated bumps: Spring Kafka 4.1.0 plus the now-mandatory `spring-boot-starter-kafka`, SpringDoc 3.0.3, `resilience4j-spring-boot4` replacing the boot3 artifact, Micrometer pins delegated to the Boot BOM. Details and upstream references in `knowledge/spring-boot-4-upgrade.md`.

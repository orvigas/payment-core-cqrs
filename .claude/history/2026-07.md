# July 2026

## 2026-07-22 — Target stack moved from Spring Boot 3.5.16 to 4.1.0

Governance docs (TECH_STACK.md, CLAUDE.md, backend-engineer rule) now target Spring Boot 4.1.0, the latest stable line. Coordinated bumps: Spring Kafka 4.1.0 plus the now-mandatory `spring-boot-starter-kafka`, SpringDoc 3.0.3, `resilience4j-spring-boot4` replacing the boot3 artifact, Micrometer pins delegated to the Boot BOM. Details and upstream references in `knowledge/spring-boot-4-upgrade.md`.

## 2026-07-22 — Repo put under git; multi-tool agent layer added

The project was not version-controlled until today; `git init` with a baseline commit of the existing scaffold. CLAUDE.md's project-state section had drifted (it still claimed no build files existed) and was synced with reality. The Axon/MongoDB event-store decision, previously only in session memory, is now ADR-001 in `knowledge/decisions/`. Added the cross-tool layer for multi-agent work: root `AGENTS.md` (thin pointer, OpenCode and other tools), `opencode.json`, `.claude/templates/` (previously referenced by rules but missing), checked-in `.claude/settings.json` with a permission allowlist, and a PostToolUse hook that flags coding-standard violations in edited Java files.

## 2026-07-22 — Agent roles, task ledger, ArchUnit gate, CI; Axon pin corrected

Roles became executable: five subagent definitions in `.claude/agents/` (architect, backend-engineer, test-engineer, code-reviewer, security-reviewer) with `roles/` as a pointer, a claim-based task ledger in `tasks/` seeded with T-001 through T-005, the workflow state machine in `workflow/DEVELOPMENT_WORKFLOW.md`, and slash commands `/new-task`, `/implement`, `/review`, `/adr`. ARCHITECTURE_RULES are now enforced by ArchUnit tests in `src/test/java/com/orvigas/architecture/`, and GitHub Actions CI runs `mvn verify` as the merge gate. JaCoCo excludes the bootstrap class so the 95% floor is satisfiable before feature code exists.

Running the build for the first time exposed that the pinned Axon version 4.10.5 never existed on Maven Central (the 4.10.x line ends at 4.10.4, verified against the repository metadata). Corrected to 4.10.4 in `pom.xml`, TECH_STACK.md, CLAUDE.md, and ADR-001. The BOM pins the MongoDB extension to 4.10.0. Lesson: a pinned version is only trustworthy after a build has resolved it.

Moved `AGENTS.md` and `opencode.json` from the repo root into `.opencode/` to match OpenCode's project-directory convention. Updated the cross-references in CLAUDE.md, README.md, and roles/README.md accordingly; contents of both files are unchanged.
